COMO O JS ACHA AS PEÇAS DO HTML (os ids)


o id é o NOME de cada peça. o js usa esse nome pra achar.

no html:
  <input id="nome">      -> campo de nome
  <input id="idade">     -> campo de idade
  <p id="resultado">     -> onde aparece a resposta
  <p id="erro">          -> onde aparece o erro

no js:
  document.getElementById("nome").value

  leitura 5 aninhos:
  "documento, pega a peça que se chama 'nome' e me fala
  o que tá escrito dentro dela"

  nível 5 aninhos ainda mais:
  "mãe, pega a caixinha azul e me diz o que tem dentro"

CUIDADO: id no html tem que ser IGUALZINHO no js. uma
letra diferente e já era, o js fala "undefined" (que
significa "não achei nada"). já aconteceu comigo rsrs

e pra ESCREVER na tela, é quase igual:
  document.getElementById("resultado").innerText = "oi"

  "documento, pega a peça chamada 'resultado' e escreve
  'oi' dentro dela". o innerText é o que aparece.

A CONTINHA DO NASCIMENTO (passo a passo bem devagar)
==============================================

imagina que a Maria digitou:
  nome: Maria
  idade: 17

Passo 1 - o if que confere o nome:

  if (nome === "") { ... }
  "se nome for exatamente igual a vazio"

  nome vale "Maria". então:
  "Maria" === "" ? -> FALSO (não é vazio ué)

  como é falso, NÃO entra no if. e aí segue reto. certo?

Passo 2 - o if que confere a idade:

  if (idade === "" || idade < 0 || idade > 120) { ... }
  "se idade for vazio OU idade menor que 0 OU idade
   maior que 120"

  idade vale "17" (texto, sempre vem como texto do input!)
  "17" === ""    ? -> FALSO
  "17" < 0       ? -> FALSO
  "17" > 120     ? -> FALSO

  se tá TUDO falso, não entra no if. segue reto. certo?

Passo 3 - a continha do nascimento:

  idade = Number(idade);            // "17" vira 17
  let anoNascimento = anoAtual - idade;
  // anoAtual é 2025, então: 2025 - 17

  fazendo na unha (armar a conta):

      2025
    -   17
    --------
      2008

  (empresta do 2 pra virar 15, 15 - 7 = 8. aí o 2 virou 1,
   e 1 - 1 = 0. o 2 do 2025 fica sozinho. deu 2008)

  Então ela nasceu mais ou menos em 2008

Passo 4 - a maioridade (um if disfarçado):

  let maioridade = idade >= 18 ? "maior de idade" : "menor de idade";

  leitura 5 aninhos:
  "se idade for maior ou igual a 18, então usa a 1ª opção,
   senão usa a 2ª"

  17 >= 18 ? -> NÃO (falso)
  então maioridade vira "menor de idade"

  esse "? :" aí é só um if curtinho. se a condição for
  verdadeira, pega o que tá antes do ":". senão, o que
  tá depois. pode chamar de "if de bolso" kkkk

Passo 5 - a frase final (juntando tudo com +):

  "Olá " + "Maria" + "! Você tem " + 17 +
  " anos, nasceu mais ou menos em " + 2008 +
  " e é " + "menor de idade" + "."

  cada + é um "grampear" (emendar as coisas). o resultado
  é uma frase só, emendada:

  Olá Maria! Você tem 17 anos, nasceu mais ou menos em
  2008 e é menor de idade. (e um emoji pra ficar bonito)

DICAS QUE ME SALVARAM


- se a página tá SEM COR (feia): a linha do <link> tá
  errada OU o style.css não tá na mesma pasta

- se o botão NÃO FAZ NADA: a linha do <script> tá errada
  OU o script.js não tá na mesma pasta

- pra ver o erro: abre no navegador, aperta F12 (ou
  botão direito -> Inspecionar). clica em "Console". se
  aparecer texto VERMELHO, é erro. ali aparece até o
  nome do arquivo que não achou. é o meu detetive

- tag <style> só no html
- no arquivo .css é CSS puro, SEM tag nenhuma
- no arquivo .js é JS puro, SEM tag nenhuma
